title: TP1 - Infrastructure SCCM
---

Dans ce travail valant **15%** de la note, vous devez démontrer au professeur que votre infrastructure SCCM a bien été configurée.

## Éléments évalués

**Le serveur SCCM est correctement installé:**

- Son nom d'hôte est significatif
- Son adresse IP est conforme à l'énoncé
- Tous les composants prérequis sont installés ou configurés adéquatement
  - Microsoft SQL Serveur
  - IIS
  - Windows ADK
- Extension du schéma
- Conteneur SYSTEM\System Management et permissions correctes

**Le site SCCM est correctement configuré:**

- Méthodes de découverte:
  - La méthode de découverte de système est configurée et se nourrit dans l'OU des postes de travail
  - Les postes de travail membres du domaine apparaissent dans la liste d'appareils
- Limites et groupes de limites:
  - Trois limites correspondant aux trois segments du réseau, sous forme de **Plage d'adresses IP**
  - Deux groupes de limites correspondant aux deux sites physiques **Longueuil** et **Saint-Trou**
  - Association correcte entre les limites et les groupes de limites
  - Les groupes de limites sont configurés pour l'assignation automatique et réfèrent au serveur de Longueuil
- Déploiement du client
  - Le compte Client Push est configuré dans Active Directory
  - Le GPO est correctement configuré (droits admin et pare-feu) et correctement déployé aux postes de travail
  - Le site SCCM est correctement configuré pour le push de client
  - Le client est correctement installé sur tous les postes de travail de l'environnement
  - Les données d'inventaire matériel des postes de travail sont visibles dans l'explorateur de ressources

## Déroulement de l'évaluation

Préparez-vous à montrer au professeur les éléments suivants:

### Sur le contrôleur de domaine:

- `ADSIEdit.msc`, montrant le conteneur System\System Management
- `GPMC.msc`, montrant le GPO pour Client Push

### Sur le serveur SCCM

- `HOSTNAME`
- `IPCONFIG /all`
- `Appwiz.cpl`
- L'explorateur de fichiers
- La commande PowerShell suivante: `Get-WindowsFeature web* | ? Installed`

### Dans la console SCCM

- Administration / Configuration de la hiérarchie / Méthodes de découverte
- Administration / Configuration de la hiérarchie / Limites
- Administration / Configuration de la hiérarchie / Groupes de limites
- Administration / Configuration de la hiérarchie / Forêts Active Directory
- Administration / Configuration de site / Sites / Paramètres d'installation du client / Installation Push du client
- Actifs et conformité / Appareils
