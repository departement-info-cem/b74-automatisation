Bienvenue dans le cours d'automatisation de systèmes. Dans ce cours, vous apprendrez à effectuer l'administration automatisée d'un parc informatique d'entreprise composé de postes de travail Windows, à l'aide du logiciel SCCM ainsi que de divers outils et techniques. Le cours sera principalement orienté Windows.

Vous retrouverez sur ce site le résumé de chaque cours dans la section [Cours](/cours/01). Les protocoles de laboratoire se trouvent dans la section [Laboratoires](/labs/01). Finalement, les énoncés des différents TP à livrer dans ce cours sont consignés dans la section [Travaux pratiques](/tp/tp1). Il y a également plusieurs [tutoriels](/tutos/01) et [astuces](/astuces/01) qui sont mis à votre disposition.
